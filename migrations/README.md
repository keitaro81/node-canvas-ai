# DB マイグレーション

このディレクトリは Supabase（本番・ステージング両DB）に手動適用する SQL を、適用順に番号付きで管理する。

## 運用
- Supabase Dashboard → SQL Editor に各ファイルの内容を貼って実行する。
- **番号順に実行**。スキーマ（`*_schema.sql`）→ データ移行（`*_backfill.sql`）の順。
- **本番DB（srlhhilvjdivftbwbgxz）とステージングDB（jihxtqadtdoimpokwjfh）の両方**に適用する。
- 各ファイルは冪等（再実行しても壊れない）になるよう書く。
- 適用後、各ファイル末尾の「検証クエリ」を実行して結果を確認する。
